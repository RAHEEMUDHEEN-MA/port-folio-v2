FINTECH FIELD OPERATIONS & REPORTING DASHBOARD — PRODUCT OWNERSHIP

Frontend Product Engineering — Analytics & Geo Systems

Context

Owned and delivered the complete frontend system of a fintech field-operations and reporting platform for a loan recovery company, working closely with a senior backend engineer. Took responsibility for frontend system design, data flow modeling, and UI/UX decisions based on backend API contracts. Implemented field-agent tracking using API polling, where mobile devices periodically send geo-location updates to the server and the frontend reconstructs time-ordered movement paths and visit timelines from coordinate arrays. Built hierarchy-based dashboards used by regional heads, state heads, managers, and operations teams to monitor collections, attendance, visits, and performance. Integrated Frappe APIs, Google Maps, and OpenStreetMap to support geospatial visualization and operational reporting.

Problem Statement

Loan recovery operations lacked centralized visibility into field-agent activity and hierarchical performance metrics. Existing systems were fragmented, relied heavily on manual reporting, and did not provide timely operational insights for decision-makers.

System Flow / Design Decisions

  • Owned frontend system architecture and UI/UX decisions while integrating with backend APIs developed by a senior backend engineer
  • Implemented polling-based geo-location visualization to ensure reliable tracking across varying mobile network conditions
  • Reconstructed agent movement paths and visit timelines from ordered geo-coordinate arrays on the frontend
  • Designed hierarchy-driven reporting views aggregating data across regional head, state head, manager, and field-officer levels
  • Integrated Google Maps and OpenStreetMap for route visualization, nearby-party discovery, and operational context
  • Built frontend workflows for CRUD operations, task assignments, and activity logs to support daily field operations

Impact & Outcomes

  • Enabled centralized visibility into real-time and historical field-agent movement through frontend-driven visualization
  • Improved decision-making for managers through hierarchy-based reporting dashboards
  • Reduced dependency on manual status tracking and ad-hoc reports
  • Supported daily monitoring and coordination of large field teams in loan recovery operations
